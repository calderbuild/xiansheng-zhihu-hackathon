# 先声

找到已经做过这件事的人。

线上体验：https://xiansheng-313076-9-1338128086.sh.run.tcloudbase.com/

## 这是什么

你在纠结要不要做一件事，比如读研、转行、转专业，但不知道该去找谁聊。先声会从知乎公开内容里找真的做过这件事的人，你不用先想好目标是谁，只要把处境写清楚就行。找不到匹配的人，它会老实说找不到，不会硬凑几个不相关的答主充数。

选中一个候选人后，先声会基于他真实写过的内容生成一段开场白，会提到他具体写了什么、和你的处境哪里重叠，不是"你好想请教一下"那种模板句子。生成完自己复制去发私信，知乎开放平台没有代发私信的接口，这一步没法自动化。

知乎黑客松 2026·校园新锐季参赛作品，赛道：灵魂匹配局。

## 核心流程

1. 描述正在纠结的处境
2. 调用知乎搜索接口，在真实公开内容里寻找已经做过这件事的人
3. 没有匹配结果时展示原因，不编造候选人
4. 选中一个候选人
5. 基于其真实内容调用知乎直答接口生成定制开场白
6. 复制开场白，自己去发私信

可选接入知乎 OAuth 登录：登录后用你关注的人做加权排序，不登录也能用完整的核心流程。

## 技术栈

- Next.js 16（App Router）+ TypeScript + Tailwind v4
- API Routes 当薄后端，没有额外的服务端框架
- 部署在腾讯云 CloudBase 云托管，push 到 main 自动构建发布
- 直接调用知乎开放平台官方接口（知乎搜索 + 直答 Agent），生成提示词明确要求只能引用真实传入内容

## 本地运行

```bash
npm install
npm run dev      # http://localhost:3000
npm test         # 全部走 mock，零网络请求
npm run lint
npx tsc --noEmit
```

需要在 `.env.local` 里配置知乎开放平台的 `ZHIHU_ACCESS_SECRET`、`ZHIHU_OAUTH_APP_ID`、`ZHIHU_OAUTH_APP_KEY`、`ZHIHU_OAUTH_REDIRECT_URI` 等环境变量（不在仓库里，需自行在 developer.zhihu.com 申请）。
